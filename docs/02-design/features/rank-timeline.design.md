# 순서별 예상시간 설계

- 기존 시뮬레이션의 현재 순서 후보(첫 번째 경로)를 관찰하여 각 앞 순서 이하가 되는 최초 시각을 기록한다. 추가 난수나 사건은 생성하지 않는다.
- 입장·앞 팀 취소·내 뒤로 미루기 모두 기록에 반영한다. 두 팀 동시 호출로 건너뛴 순서는 같은 시각으로 기록하고 UI에 이 의미를 설명한다.
- 도착시간이나 추천 순서 선택과 무관하다. 현재 순서를 유지하는 경우의 평균이며, 360분 내 미도달 사례가 하나라도 있으면 평균은 ‘범위 밖’으로 표시한다.
- Worker 결과에 rankTimeline을 추가한다. 현재 순서 결과 카드 다음에 ‘앞 순서가 되는 예상시간’ 카드를 표시한다. 순서·평균시각·현재부터 남은 분을 목록으로 표시하고 길면 카드 안에서 스크롤한다.
- 현재 1번째이면 이미 맨 앞이며 다음 호출을 기다린다는 안내를 표시한다. 1번째 도달과 실제 호출은 구분한다.
- 기존 호출 결과 보존, 도달시간 단조, 동시 호출, 취소·미루기, 현재1번째, 미도달 처리와 Worker 분할 실행을 검사한다.
