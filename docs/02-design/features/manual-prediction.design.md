# 버튼 실행 예측과 자동 기록 · 2026-10-31

기존 DESIGN.md와 MODEL.md를 다음 요구로 보완한다.

- 입력, 시간 경과, 새로고침, 탭 전환, 기록 삭제는 예측을 실행하지 않는다. 유효한 입력의 예측하기 제출만 Worker를 실행한다. 예시도 입력만 채운다.
- 완료된 결과는 제출 시각·입력·계수의 스냅샷으로 유지한다. 입력 변경 또는 시간 경과 시 다시 예측할 것을 안내하며 이전 결과를 새 입력의 결과처럼 표시하지 않는다. 탭 전환은 진행 중 요청을 취소하고 결과를 비운다.
- 다른 매장 예측 요청에는 현재 날짜·분·순서를 관측값으로 포함한다. 성공한 요청에 대해서만 해당 기록을 저장한다. 같은 분의 마지막 기록과 순서가 같으면 중복 저장하지 않는다. 같은 분의 순서 변화는 제출 순서를 보존하되 0분 구간은 학습하지 않는다.
- 오늘의 직전 관측보다 순서 숫자가 커지면 self-defer로 분류한다. 미루기까지의 구간을 제외하고 이후 관측부터 속도 추정을 재개한다. 기록은 직접 추가·수정할 수 없고 삭제·초기화만 가능하다. 삭제는 입력 순서를 덮어쓰지 않는다. 기존 기록은 읽기 가능하게 유지한다.
- 가이드에는 입력 후 예측하기 → 자동 기록, 순서 증가의 미루기 판정, 삭제 후 재예측, 새 방문/매장 변경 시 초기화, 동일 분 중복 정책을 명시한다.
- 모든 예측 결과에 사용한 계수 스냅샷을 표시한다. 현재 비교 중인 순서 r의 한 팀 감소 평균은 사후분포에 대한 E[1/(μ+(r−1)(c+dq))]로 계산한다. 1번째는 다음 호출 대기로 구분한다. 기본 호출 평균 E[1/μ]와 대표 서비스율 E[μ]도 설명한다.
- 취소·미루기 확률은 다른 팀 한 팀이 계속 대기할 때 10분 내 최소 1회 확률 1−exp(−10c), 1−exp(−10d)이며 고정 가정임을 표시한다. 내 뒤로 미루는 비율 q=50%와 단위도 표시한다. 전체 대기 중 발생할 확률로 오해시키지 않는다.
- 검증: 자동 기록의 중복/동일 분/미루기/날짜/삭제/잘못된 입력, 계수와 시뮬레이션의 일치, 버튼 외 실행 방지, 실제 브라우저 흐름, 전체 테스트 및 빌드.
