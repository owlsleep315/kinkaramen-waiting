# 다른 매장 기록만 사용하는 예측

- 오늘 현재까지의 다른 매장 기록이 0~1개이면 기존 킨카라멘 분포를 사용한다. 현재 제출 기록도 개수에 포함한다.
- 기록이 2개 이상이면 킨카라멘 평균·30분 사전정보·분포를 사용하지 않는다. 유효 구간의 기존 정확 전이 likelihood를 최대화하는 비음수 호출률 μ를 사용한다. 취소율 c, 미루기율 d, 교차비율 q는 기존 고정값을 유지한다.
- 유효 노출 T와 각 감소 단계의 h(r−1)에 대해 log likelihood의 μ 관련 항은 −Tμ + Σ log(μ+h(r−1)). 미분이 0 이하이면 μ=0, 아니면 [0, 감소수/T]에서 이분법으로 최대점을 구한다. 추정값 하나를 기존 시뮬레이터의 rates=[μ], weights=[1]로 전달한다. 킨카라멘 학습·고정 파일은 변경하지 않는다.
- 시간 차이가 없는 기록·미루기 구간만으로는 추정하지 않는다. 2개 이상인데 유효 구간이 없으면 결과 대신 추가 관측 안내를 표시하고 기록은 보존한다. 이 경우는 예측 오류가 아니라 기록 수집 단계다. 추가 관측 후 다시 예측할 수 있어야 한다.
- 0감소 구간은 유효하며 최대우도 호출률은 0일 수 있다. 이 경우 1번째 호출 평균은 무한대이므로 화면에는 추정 불가를 표시하고 호출 시뮬레이션은 범위 밖으로 처리한다. 임의의 킨카라멘 대체값·양의 최소 호출률을 넣지 않는다.
- 계수 카드·모델 설명·기록 가이드에 현재의 근거(킨카라멘 임시 기준 / 이 매장 기록만)를 명시한다. 다른 매장에서는 호출률 추정값을 고정하고 사건 발생 시간의 무작위성만 계산한다는 사실을 설명한다.
- 검증: 2개 시점 즉시 전환, likelihood 최대점, 0감소/고정 행동률, 유효 구간 없음/이후 관측 재개, 날짜·삭제 경계, 무한 시간 표시, 전체 테스트와 빌드.
