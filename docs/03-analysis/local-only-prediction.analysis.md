# local-only-prediction 완료 및 설계 대조

기준: `docs/02-design/features/local-only-prediction.design.md`

- 0~1개 오늘 기록은 기존 킨카라멘 분포, 2개 이상은 해당 매장 구간의 최대우도 추정으로 분기한다. 추정 함수는 킨카라멘 호출률·사전분포·30분 노출 강도를 참조하지 않는다.
- 기존 취소·미루기·교차율은 수정하지 않았다. 정확 구간 likelihood에서 고정 행동률을 반영하므로 감소량을 서비스율로 곧바로 바꾼 뒤 행동률을 중복 가산하지 않는다.
- 같은 분·미루기 구간만 있으면 예측 대신 기록을 보존한다. 다음 유효 관측 이후 예측 가능하며 킨카라멘 fallback은 차단한다.
- 0감소 구간은 보존한다. 호출률 0이면 임의의 최솟값 없이 호출 미발생·무한 대기를 처리하고, 계수 카드는 추정 불가와 다음 관측 안내를 표시한다.
- 기록 가이드·모델 설명·결과 카드·README·MODEL 문서를 새 동작과 일치시켰다.
- 자동 테스트 60개, 타입 검사 포함 프로덕션 빌드 통과. Chrome에서 기록 수집 → 보류 → 다음 분의 자체 예측 흐름과 계수 표시를 확인했다.

요구사항 대비 누락은 발견하지 못했다. 실제 매장 정확도 검증 및 모바일 실기기 확인은 별도 항목이다. 호출률 추정값의 불확실성은 포함하지 않고 사건 시간의 확률적 변동을 시뮬레이션한다.
