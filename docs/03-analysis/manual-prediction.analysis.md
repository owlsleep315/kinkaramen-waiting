# manual-prediction 설계 대조 및 완료 기록

2026-10-31 · 기준: `docs/02-design/features/manual-prediction.design.md`

| 요구 | 구현 및 확인 |
|---|---|
| 버튼으로만 예측 | App의 자동 예측 effect 제거. submit의 run에서만 predict 호출. Chrome 입력/탭/새로고침 검증 |
| 결과 스냅샷 | 입력 변경·시간 경과 안내. 결과 입력과 modelInfo 유지. 탭 전환/삭제 시 clear로 요청 무효화 |
| 다른 매장 자동 기록 | 요청 시 관측값 포함, 성공 callback에서 저장. 킨카라멘은 저장하지 않음 |
| 직접 추가/수정 금지 | 기록 폼·수정 버튼·updateRecord 제거. 삭제/초기화만 제공 |
| 순서 증가 미루기 | 오늘 직전 기록과 비교해 self-defer. 해당 구간 제외, 이후 정상 구간 학습 테스트 |
| 중복과 동일 분 | 같은 분·같은 순서 연속 입력은 중복 없음. 순서 변화는 ordered로 보존. 4→6→4 회귀 테스트 |
| 사용법 | 자동 저장·미루기 판정·잘못된 기록 삭제·재예측·새 방문 초기화·같은 분 처리 안내 |
| 모든 결과 계수 표시 | 공통 결과 카드에 선택 순서별 혼합 평균과 고정 행동 확률, 단위·근거·계산식 표시 |
| 실제 계수 일치 | Worker가 사용한 posterior와 행동률을 modelInfo로 반환. 킨카라멘·다른 매장 수치 테스트 |

54개 테스트와 프로덕션 빌드 통과. 테스트 중 발견한 동일 분 순서 복귀 기록의 잘못된 중복 제거를 수정하고 전체 테스트를 다시 통과했습니다. 요구사항 대비 누락은 발견하지 못했습니다. 정확도 개선이나 실측 확률 보정을 주장하지 않으며 기존 추정 모델을 유지합니다.

브라우저 검증은 로컬 데스크톱 Chrome으로 수행했습니다. 실제 모바일·배포 사이트 확인은 후속 검증 항목입니다.
